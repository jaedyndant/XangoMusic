# Xango Music

Developed by **jaedyn trinidad**

A modern redesign of the Xango Music website built with **Next.js 14**. It integrates a world music record store, distribution services, and the Xangoma magazine into a single, responsive platform.

## Features
- **Record Store**: Curated catalogue of world music vinyl and CDs.
- **XMD Distribution**: Global distribution services for artists.
- **Xangoma Magazine**: Editorial news, reviews, and cultural insights.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Open the site**:
   Navigate to [http://localhost:3000](http://localhost:3000).

## Project Structure
- `/app`: Main application routes and layouts.
- `/app/components`: Reusable UI components (Header, Footer, NewsFeed, etc.).
- `/app/catalogue`: Record store and filtering logic.
- `/app/magazine`: Editorial content and articles.
